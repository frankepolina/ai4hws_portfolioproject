This project was created as part of the course AI for Human-Water-Systems at TU Berlin, Summer Term 2026. 

How this project is set up:
- src contains all .py scripts with functions
- main.py runs all necessary scripts from getting data to computing input features.

- dev contains development notebooks of the functions found in src as well as
- Final data analysis was done in the notebooks >explore_features.ipynb< and >analysis_features_clusters.ipynb<.

How to run this project:
1) Rename the >nec_data<> folder to >data<, so that the scripts can run. The nec_data folder contains files, which were downloaded manually and changed and are therefore not retrieved via API/Download calls. 
2) run the main.py from your terminal
3) cross all fingers no errors pop-up! 


Note: Gen AI (ChatGPT and Claude) were used in the development of the scripts and notebooks. 
Main tasks were error resolving, workflow suggestions and creation of plots and summary tables. Code blocks and functions, which were entirely adapted from ChatGPT or Claude are commented as such throughout the project.
